# Performance

1. 改善する操作と指標を決め、目標があれば記録する。問題が出る条件で変更前の値を測り、環境、データ量、負荷、キャッシュの状態を記録する。値がばらつく場合は複数回測る。
2. トレースやプロファイル、区間ごとの計測で負荷が集中している箇所を特定する。証拠が足りなければ計測条件を見直す。原因を絞れなければ、試した条件と不足している情報を報告して止まる。
3. 計測で特定した箇所を改善する。不要な処理や重複する処理を減らせるかを先に確かめ、変更を一つずつ試す。
4. 手順 1 と同じ条件で測り直し、ばらつきを踏まえて改善を判定する。影響しうる他の指標を確かめ、関連テストで振る舞いを確認する。比較できなければ、測れた値と比較できない理由を記録する。
5. 依頼にコミットや PR 作成が含まれる場合は、それぞれ **commit** と **create-pr** を使う。PR の本文には計測条件と変更前後の結果を添える。

**返信:** 計測条件、原因、変更前後の値と差、再計測の手順や記録、未確認事項。PR を作った場合はリンクを添える。
