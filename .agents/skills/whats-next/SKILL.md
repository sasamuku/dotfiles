# What's Next

対象: $ARGUMENTS (省略時は会話で進めている作業)。

[progress-view](../progress-view/SKILL.md) を読み、状況の確認と共通表示を適用する。

共通表示の後に **次の一手** として、目的達成に必要な行動を一つ推奨する。進める工程、今行う理由、完了条件、必要な前提・判断・承認を簡潔に添える。

- 合意済みの順序と依存関係を優先し、成果の反映・検証を事務的な整理より先に扱う。無関係な既存課題や、依頼されていない整理は候補にしない。
- 外部対応や判断待ちなら再開条件を示す。待ちの間の作業は目的に必要で独立して進められるものだけとし、判断材料が足りなければ、その確認を次の行動にする。
- 複数の行動は依存関係や並行作業の説明に必要な場合だけ、優先順を付けて示す。完了条件を満たしていれば「次の対応は不要」とする。

提案だけで新たな作業を開始せず、提案を合意済みの計画として扱わない。
