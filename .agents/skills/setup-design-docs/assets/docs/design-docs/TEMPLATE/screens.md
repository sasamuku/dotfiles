### 編集画面（記入例）

```
+----------------------------------+
| ← 一覧            [public ▾]     |
|                                  |
| タイトル（placeholder、空でよい）  |
|                                  |
| 本文 textarea                    |
| （画面の大半。開いた時点でフォーカス）|
|                                  |
+----------------------------------+
```

主要な挙動:

- 開いた瞬間に本文へフォーカス。1 秒以内に書き始められることが受け入れ条件。
- 入力停止 2 秒で自動保存（PATCH /pages/:id）。保存ボタンは置かない。
- 保存状態は「保存中… / 保存済み」の控えめな表示のみ。失敗時だけ目立たせる。

状態:

- 空ページ: placeholder のみ。チュートリアルは出さない。
- 保存失敗: 本文は消さずリトライ導線を出す。
