### 決定 1: 保存は明示ボタンなしの自動保存のみとする（記入例）

- **決定**: 保存ボタンを置かず、入力停止後のデバウンスで自動保存する。
- **根拠**: 入力のたびに保存操作を求めず、保存忘れを減らすというこの機能の目的に合う。
- **却下した代替案**: Cmd+S 併用 — 自動保存が十分速ければ冗長。ショートカット衝突の考慮が増えるだけと判断。
