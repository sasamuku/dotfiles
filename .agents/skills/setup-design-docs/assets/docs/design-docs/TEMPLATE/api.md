### PATCH /pages/:id（記入例）

自動保存から数秒デバウンスで呼ばれる。冪等。

リクエスト:

```json
{ "title": "散歩メモ", "content": "今日は [[井の頭公園]] まで。 #日記" }
```

レスポンス 200:

```json
{ "page": { "id": "...", "title": "散歩メモ", "updatedAt": "..." } }
```

エラー:

- 404 — 存在しない id、または private ページを他人が触った場合（存在を漏らさないため 403 ではなく 404）
