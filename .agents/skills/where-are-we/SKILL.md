# Where Are We

対象: $ARGUMENTS (省略時は会話で進めている作業)。

[progress-view](../progress-view/SKILL.md) を読み、状況の確認と共通表示を適用する。

共通表示の後に **現在** として、取り組んでいる内容と直近の確認結果・根拠を簡潔に添える。未着手・判断待ち・完了済みなら、その状態を示す。

作業履歴やツール操作を時系列に並べない。新しい計画や改善提案は求められた場合だけ示す。
