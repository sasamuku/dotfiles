# Anything Else

対象: $ARGUMENTS (省略可)。

## 収集

1. **会話**: 先送りした話題・TODO・ユーザーの懸念
2. **git**: `git status`、`git log --oneline origin/HEAD..HEAD`、`git worktree list`、`git stash list`
3. **issue / PR**: セッションで触れたものの状態・コメント・ラベルが実態と合うか `gh` で確認
4. **プロセス**: 自分が起動した dev server・watcher・エミュレータの残り
5. **規約**: CLAUDE.md・メモリの「〜したら〜する」ルーティンに今回の変更が該当するか

## 出力

3 区分、通し番号。各項目 1〜2 行で根拠 (ファイル・issue 番号・数値) を添える。空の区分は省略する。

- **今やったほうがいい (OK をもらえたらやる)**: おすすめ (やる / やらない) と所要時間の目安を付ける
- **後回しでいい**: issue で追える状態にする。未起票なら起票を提案する
- **問題なし**: 確認済みで問題のなかった観点

## ルール

- 提案のみ。実行は番号で承認を得てから。issue / PR 作成は `create-issue` / `create-pr` に従う
- 削除系 (worktree・stash・ブランチ) は対象と中身の有無を明示し、個別に承認を得る
- 確認していない観点を「問題なし」に書かない
