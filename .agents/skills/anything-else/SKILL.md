# Anything Else

対象: $ARGUMENTS (省略可)。

[progress-view](../progress-view/SKILL.md) を読み、状況の確認と共通表示を適用する。

今回の変更・操作に関係する未対応の依頼・約束や未回答の懸念、成果の未反映、検証漏れ、差分や退避編集の保全、issue / PR の記録との不整合、今回起動した処理の残存による支障、必須の後処理を必要な範囲で確認する。各候補は目的との関係と、対応しない場合の具体的な支障を確かめる。

- 同期・worktree・ブランチ・stash の整理は、今回の目的への支障か明示的な依頼がある場合だけ扱う。一般に望ましい、短時間でできるという理由では提案しない。
- 無関係な改善や、追跡済みで状況が変わらない残件は再掲しない。ただし今回の完了条件に必要な残件は省かない。
- 意図して残したプロセス・データや、用途・作成者・今回との関係が不明なものは、残っているだけで操作候補にしない。

共通表示の後に **残対応** として、根拠と放置した場合の支障を添えて通し番号で示す。必要なら「今必要」「待ち・後で対応」に分け、空の区分は省く。完了条件未達・未完の約束・具体的な支障があるものを「今必要」とし、成果の反映・検証を優先する。外部対応・判断待ちや、対応時期を分ける合意があるものは「待ち・後で対応」とし、理由・再開条件と、あれば既存の追跡先を添える。起票は必要な継続作業に限って提案する。

残件がなければ「追加対応なし」と確認範囲だけ添える。未確認の観点を問題なしとせず、問題のなかった観点は列挙しない。

提案のみ。実行は番号で承認を得てからとし、issue / PR 作成は `create-issue` / `create-pr` に従う。削除系は対象と中身の有無を明示し、個別に承認を得る。
