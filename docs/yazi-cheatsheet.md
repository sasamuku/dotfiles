# yaziの基本操作方法

ターミナルファイルマネージャ [yazi](https://github.com/sxyazi/yazi) のチートシート。
`y` コマンドで起動する（このdotfilesのシェルラッパー。`.config/zsh/functions/yazi.zsh`）。

## 画面構成

```
┌──────────┬──────────────┬──────────────┐
│  親       │  現在の       │  プレビュー   │
│  ディレクトリ│  ディレクトリ  │  (ファイル内容│
│          │  (カーソル)   │   /中身一覧)  │
└──────────┴──────────────┴──────────────┘
```

---

## 1. 移動

### カーソル移動（Vimと同じ）
```
    k (上)
    ↑
h ← ↓ → l
    j (下)
```

| キー | 説明 |
|------|------|
| `h` / `←` | 親ディレクトリへ |
| `l` / `→` | カーソル位置のディレクトリに入る |
| `j` / `k` | カーソル下 / 上 |
| `gg` | リスト先頭へ |
| `G` | リスト末尾へ |
| `J` / `K` | プレビューを下 / 上へスクロール |

### ジャンプ
| キー | 説明 |
|------|------|
| `g` → 各キー | ショートカットへジャンプ（`g` を押すと候補が表示される） |
| `z` | fzf でディレクトリ移動・ファイルを表示 |
| `Z` | zoxide でよく行くディレクトリへジャンプ（要 zoxide） |

---

## 2. 選択

| キー | 説明 |
|------|------|
| `Space` | カーソル位置の選択をトグル |
| `v` | ビジュアルモード（範囲選択） |
| `Ctrl+a` | 全選択 |
| `Ctrl+r` | 選択を反転 |
| `Esc` | 選択解除 |

---

## 3. ファイル操作

### コピー・移動（Vim風の yank & paste）
| キー | 説明 |
|------|------|
| `y` | コピー（yank） |
| `x` | カット（貼り付けると移動になる） |
| `p` | 貼り付け |
| `P` | 上書きで貼り付け |
| `Y` / `X` | yank の取り消し |

### 作成・削除・リネーム
| キー | 説明 |
|------|------|
| `a` | 新規作成（末尾 `/` でディレクトリ） |
| `r` | リネーム |
| `d` | ゴミ箱へ移動 |
| `D` | 完全削除 |

### 開く
| キー | 説明 |
|------|------|
| `Enter` / `o` | 開く（テキスト系は `$EDITOR` = nvim。`:q` で yazi に戻る） |
| `O` | 開き方を選んで開く |
| `Tab` | ファイル情報をポップアップ表示（開かない） |

### パスのコピー
| キー | 説明 |
|------|------|
| `cc` | ファイルの絶対パス |
| `cd` | ディレクトリのパス |
| `cf` | ファイル名 |
| `cn` | 拡張子なしのファイル名 |

---

## 4. 検索・フィルタ

| キー | 説明 |
|------|------|
| `f` | フィルタ（表示を絞り込む） |
| `/` / `?` | 前方 / 後方に find |
| `n` / `N` | 次 / 前の find 結果へ |
| `s` | ファイル名で再帰検索（要 fd） |
| `S` | ファイル内容で再帰検索（要 ripgrep） |
| `Ctrl+s` | 検索を中止 |
| `.` | 隠しファイルの表示切り替え |

---

## 5. ソート・タブ・その他

### ソート（`,` に続けて）
| キー | 説明 |
|------|------|
| `,a` / `,A` | アルファベット順（大文字で逆順、以下同じ） |
| `,n` / `,N` | 自然順 |
| `,m` / `,M` | 更新日時順 |
| `,s` / `,S` | サイズ順 |
| `,e` / `,E` | 拡張子順 |

### タブ
| キー | 説明 |
|------|------|
| `tt` | 新しいタブを開く |
| `1`〜`9` | N番目のタブへ |
| `[` / `]` | 前 / 次のタブへ |
| `Ctrl+c` | タブを閉じる |

### シェル・ヘルプ・終了
| キー | 説明 |
|------|------|
| `;` | シェルコマンドを実行 |
| `~` / `F1` | ヘルプメニュー（全キーバインド一覧） |
| `q` | 終了して yazi 内の cwd へ cd（`y` ラッパーの機能） |
| `Q` | 終了（cd しない） |

---

## 💡 最初に覚えるべき5つ

1. `hjkl` で移動、`l` でディレクトリに入り `h` で戻る
2. `Space` で選択 → `y`（コピー）/ `x`（カット）→ 移動先で `p`
3. `a` で作成、`r` でリネーム、`d` で削除
4. `Enter` で開く（nvim が開いたら `:q` で戻る）
5. `q` で終了するとそのディレクトリに cd される
